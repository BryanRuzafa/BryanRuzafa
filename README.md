### 🧭 Sobre mí

Mi base técnica no empezó picando código, sino **administrando infraestructura**: servidores Linux, redes, protocolos y virtualización. Entender primero la máquina cambió mi forma de programar: sé qué recursos consume el servidor, cómo viajan los paquetes y cómo responde el sistema a cada petición.

```bash
$ whoami
bryan-ruzafa — Full-Stack Developer & Cybersecurity Student

$ cat trayectoria.log
[2022-2024] CFGM Sistemas Microinformáticos y Redes (SMR)   → Institut Eugeni d'Ors
[2024-2026] CFGS Desarrollo de Aplicaciones Web (DAW)       → INS Pedralbes
[2026-now ] Especialización en Ciberseguridad en Entornos TI → Institut Esteve Terradas i Illa

$ echo $OBJETIVO
Desarrollo seguro desde el minuto uno: hardening, DevSecOps y prevención OWASP.
```

- 🔐 Ahora mismo: **ciberseguridad** (bastionado, DevSecOps, análisis forense y hacking ético)
- 🛠️ Experiencia en **soporte IT** en entorno corporativo (Raventós Codorníu)
- 🌍 Castellano y catalán nativos · Inglés B2
